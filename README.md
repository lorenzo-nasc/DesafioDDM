## Como usar o projeto

1. Abra o projeto no Android Studio (versão recente, AGP 9.x).
2. Aguarde a sincronização do Gradle.
3. Rode no emulador ou dispositivo físico (`minSdk 24`).
4. Faça login com usuário `admin` e senha `1234`.
5. Cadastre um filme informando uma URL de imagem válida (ex.: uma imagem hospedada na internet) e acesse "Ver lista" para visualizar o card.
